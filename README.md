# Попутчики: совместные путешествия

Веб-приложение, где люди публикуют идеи поездок, присоединяются к ним, вместе составляют план и бюджет и общаются в чате поездки.

**Стек:** FastAPI + PostgreSQL + SQLAlchemy (backend), React + TypeScript + Ant Design (frontend).

## Выбор UI-библиотеки

Ant Design выбрана из-за простой реализации готовых компонентов, которые нужны проекту: формы с проверкой полей, карточки, списки, вкладки, выбор дат и сетка для адаптивной вёрстки. Благодаря этому все экраны выглядят единообразно, а текст остаётся читаемым без отдельной настройки стилей.

## Пользовательские сценарии и экраны

| Экран | Адрес | Кто видит | Что можно делать |
|---|---|---|---|
| Идеи поездок | `/` | все | смотреть список, фильтр «Все / Мои» |
| Вход, регистрация | `/login`, `/register` | гости | создать аккаунт, войти |
| Поездка | `/trips/:id` | все | читать описание, вступить или выйти, у организатора: изменить и удалить |
| План, Бюджет, Чат | вкладки на странице поездки | только участники | добавлять, менять, удалять пункты плана; вносить траты и видеть баланс; писать в чат |
| Создание и редактирование поездки | `/trips/new`, `/trips/:id/edit` | вошедшие (редактирование только у организатора) | заполнить форму поездки |

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```
Приложение: http://localhost:5173.
