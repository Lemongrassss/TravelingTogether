# Попутчики: совместные путешествия

Веб-приложение, где люди публикуют идеи поездок, присоединяются к ним, вместе составляют план и бюджет и общаются в чате поездки.

**Стек:** FastAPI + PostgreSQL + SQLAlchemy (backend), React + TypeScript + Ant Design (frontend).

## Выбор UI-библиотеки

Ant Design выбрана из-за простой реализации готовых компонентов, которые нужны проекту: формы с проверкой полей, карточки, списки, вкладки, выбор дат и сетка для адаптивной вёрстки. Благодаря этому все экраны выглядят единообразно, а текст остаётся читаемым без отдельной настройки стилей.

## Пользовательские сценарии и экраны

| Экран | Адрес | Кто видит | Что можно делать |
|---|---|---|---|
| Идеи поездок | `/` | все | смотреть список, фильтр «Все / Мои» |
| Вход, регистрация | `/login`, `/register` | гости | создать аккаунт, войти |
| Поездка | `/trips/:id` | все | читать описание, вступить или выйти, у организатора: изменить и удалить |
| План, Бюджет, Чат | вкладки на странице поездки | только участники | добавлять, менять, удалять пункты плана; вносить траты и видеть баланс; писать в чат |
| Создание и редактирование поездки | `/trips/new`, `/trips/:id/edit` | вошедшие (редактирование только у организатора) | заполнить форму поездки |

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```
Приложение: http://localhost:5173. 

## Запуск через Docker

```bash
cp .env.example .env        
cd backend
cp .env.example .env        
docker compose up --build
```
API будет на http://localhost:8000/docs. 

## Модель данных

- **users**: id, email (уникальный), name
- **trips**: id, title, destination, description, start_date, end_date, max_people, owner_id → users
- **members**: id, trip_id → trips, user_id → users (пара trip_id + user_id уникальна). Связь «многие ко многим» между пользователями и поездками
- **plan_items**: id, trip_id → trips, day, title, note
- **expenses**: id, trip_id → trips, paid_by → users, title, amount
- **messages**: id, trip_id → trips, user_id → users, text, created_at

При удалении поездки удаляются её участники, план, траты и сообщения.

## Структура backend (`backend/app`)

- `main.py`: создание приложения, CORS, подключение маршрутов
- `config.py`: настройки из `.env`
- `database.py`: подключение к БД и сессии
- `models.py`: таблицы SQLAlchemy
- `schemas.py`: схемы валидации запросов и ответов (Pydantic)
- `deps.py`: проверка прав доступа (текущий пользователь, участник, организатор). Пока без паролей пользователь определяется заголовком `X-User-Id` 
- `routers/`: маршруты API (`users.py`: временное создание пользователей, `trips.py`, `trip_details.py`: план, расходы, чат)
